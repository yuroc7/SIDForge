# Security policy

## Official distribution

Use only the release linked from `https://sidforge.pp.ua/`. Verify its published size and SHA-256 checksum before execution.

## Reporting a security issue

Send suspected vulnerabilities privately to `support@sidforge.pp.ua` with the subject `SID Forge security report`.

Include a clear description, affected version, reproducible user-visible behavior, and impact. Do not include passwords, private keys, customer activation data, or unrelated personal information.

Do not publish an unpatched vulnerability in a public issue.

## Repository scope

This public repository contains documentation and product images only. It is not the SID Forge source repository and does not accept source-code pull requests.
