# SID Forge support

Support email: `support@sidforge.pp.ua`

Official website: `https://sidforge.pp.ua/`

When requesting help, include:

- SID Forge version;
- Windows edition and build;
- whether the system is physical or virtual;
- the diagnostic ID shown by SID Forge;
- a short description of the stage and visible error.

Do not post diagnostic archives, account data, activation requests, credentials, private promotion codes, or complete system logs in a public GitHub issue.

This repository is for public documentation. Customer-specific troubleshooting should be sent by email.
